# @vorsteh-queue/adapter-zenstack

The official ZenStack adapter for Vorsteh Queue.

Use ZenStack ORM-backed PostgreSQL storage for your queue in minutes.

## Install

```bash
pnpm add @vorsteh-queue/adapter-zenstack @zenstackhq/orm
```

## What you get

- ZenStack ORM-based queue persistence with Prisma-compatible API
- PostgreSQL locking and picking behavior for workers
- Seamless integration with @vorsteh-queue/core
- Built-in access control, polymorphic models, and plugin system from ZenStack

## Requirements

- Node.js >= 22
- @zenstackhq/orm >= 3.0.0

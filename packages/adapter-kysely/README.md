# @vorsteh-queue/adapter-kysely

Kysely adapter for Vorsteh Queue — provides PostgreSQL job storage using Kysely with support for any compatible PostgreSQL driver.

## Installation

```bash
pnpm add @vorsteh-queue/adapter-kysely kysely
```

## Documentation

See the [Vorsteh Queue Documentation](https://vorsteh-queue.dev/docs) for detailed usage instructions.

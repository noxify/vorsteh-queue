# @vorsteh-queue/adapter-kysely

The official Kysely adapter for Vorsteh Queue.

Use Kysely-backed PostgreSQL storage for your queue in minutes.

## Install

```bash
pnpm add @vorsteh-queue/adapter-kysely kysely
```

## What you get

- Kysely-based queue persistence
- PostgreSQL locking and picking behavior for workers
- Seamless integration with @vorsteh-queue/core

## Requirements

- Node.js >= 22
- kysely >= 0.28.0

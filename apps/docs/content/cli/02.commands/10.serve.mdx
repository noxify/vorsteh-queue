Starts the GraphQL API server. Requires a `queue.config.ts` with a direct adapter configuration.

## Usage

```bash
vorsteh-queue serve
```

```bash
vorsteh-queue serve --port 4000
```

```bash
vorsteh-queue serve --no-dashboard
```

## Configuration

The serve command reads from `queue.config.ts`:

```typescript
// queue.config.ts
import { Queue } from "@vorsteh-queue/core"
import { drizzle } from "drizzle-orm/node-postgres"
import { Pool } from "pg"
import { PostgresQueueAdapter } from "@vorsteh-queue/adapter-drizzle/postgres-adapter"

const pool = new Pool({ connectionString: process.env.DATABASE_URL })
const db = drizzle(pool)
const adapter = new PostgresQueueAdapter(db)

const emailQueue = new Queue(adapter, { name: "email-queue" })
const reportQueue = new Queue(adapter, { name: "report-queue" })

export default {
  adapter,
  queues: [emailQueue, reportQueue],
  defaultQueue: "email-queue",
  port: 3000,
}
```

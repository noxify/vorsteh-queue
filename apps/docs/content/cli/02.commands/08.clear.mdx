Removes multiple jobs from the queue. Use `--status` to target a specific state or `--all` to clear everything.

## Usage

```bash
# Clear completed jobs
vorsteh-queue clear --status completed

# Clear all jobs
vorsteh-queue clear --all
```

## Valid Statuses

`pending`, `delayed`, `processing`, `completed`, `failed`, `cancelled`, `dead`

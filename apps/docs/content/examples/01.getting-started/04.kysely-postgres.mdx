An example using Kysely as the query builder with a PostgreSQL database, demonstrating recurring job scheduling.

## Setup

First, generate the project:

<Command variant="exec">
  create-vorsteh-queue my-app --template=kysely-postgres
</Command>

Then install dependencies and start the dev server:

```bash
cd my-app
pnpm install
pnpm dev
```

## What it demonstrates

- Kysely adapter setup
- Migration-based schema creation
- Recurring job scheduling
- Job handler with typed payloads

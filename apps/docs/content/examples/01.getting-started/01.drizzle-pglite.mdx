A zero-dependency-on-external-services example that uses PGlite as an embedded PostgreSQL database. Great for quick experimentation without running a Postgres server.

## Setup

First, generate the project:

<Command variant="exec">
  create-vorsteh-queue my-app --template=drizzle-pglite
</Command>

Then install dependencies and start the dev server:

```bash
cd my-app
npm install
npm run dev
```

## What it demonstrates

- Basic queue setup with Drizzle ORM
- Embedded PGlite database (no external PostgreSQL needed)
- Job registration and processing
- Simple job handler returning results

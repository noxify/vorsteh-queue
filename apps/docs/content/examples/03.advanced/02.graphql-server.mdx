A standalone GraphQL server exposing queue operations — inspect jobs, get stats, cancel, retry, and redrive from any GraphQL client.

## Setup

First, generate the project:

<Command variant="exec">
  create-vorsteh-queue my-app --template=graphql-server
</Command>

Then install dependencies and start the dev server:

```bash
cd my-app
pnpm install
pnpm dev
```

## What it demonstrates

- `@vorsteh-queue/server` setup
- GraphQL API with Yoga and Hono
- Query queue stats and job details
- Mutation operations (cancel, retry, redrive)

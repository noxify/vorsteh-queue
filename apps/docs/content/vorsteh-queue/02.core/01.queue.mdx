---
title: Queue
description: Create and manage job queues with handlers, scheduling, and lifecycle control.
---

The `Queue` class is the central API for managing jobs. It handles registration of job handlers, adding jobs, and controlling processing.

## Creating a Queue

```typescript
import { Queue, MemoryQueueAdapter } from "@vorsteh-queue/core"

const queue = new Queue(new MemoryQueueAdapter(), { name: "my-queue" })
```

For production, replace `MemoryQueueAdapter` with a PostgreSQL adapter (Drizzle, Prisma, or Kysely).

## Registering Handlers

Define how each job type should be processed:

```typescript
interface EmailPayload {
  to: string
  subject: string
}

interface EmailResult {
  messageId: string
}

queue.register<EmailPayload, EmailResult>("send-email", async (job) => {
  const id = await sendEmail(job.payload)
  return { messageId: id }
})
```

## Adding Jobs

```typescript
// Basic job
await queue.add("send-email", { to: "user@example.com", subject: "Welcome!" })

// Job with options
await queue.add(
  "send-email",
  { to: "user@example.com", subject: "Urgent" },
  {
    priority: 1,
    delay: 5000,
    maxAttempts: 5,
  }
)
```

See [Job Types](/docs/vorsteh-queue/core/job-types) for all available scheduling patterns (delayed, cron, repeating, unique, grouped).

## Queue Control

```typescript
queue.start() // Start processing jobs
queue.pause() // Pause processing
queue.resume() // Resume processing
await queue.stop() // Graceful shutdown
```

## Queue Statistics

```typescript
const stats = await queue.getStats()
// { pending, delayed, processing, completed, failed, cancelled, dead }

await queue.clear() // Clear all jobs
await queue.clear("failed") // Clear only failed jobs
```

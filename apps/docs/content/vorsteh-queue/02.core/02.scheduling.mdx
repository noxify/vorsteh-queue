---
title: Scheduling
description: Delayed jobs, recurring jobs with cron expressions, and interval-based repetition.
---

Vorsteh Queue supports multiple scheduling patterns for deferred and recurring work.

## Delayed Jobs

Schedule a job to run after a specified delay:

```typescript
await queue.add(
  "cleanup",
  { type: "temp-files" },
  {
    delay: 60000, // 1 minute from now
  }
)
```

## Recurring Jobs (Cron)

Use standard cron expressions for recurring jobs:

```typescript
await queue.add(
  "daily-report",
  { date: new Date().toISOString() },
  {
    cron: "0 9 * * *", // Every day at 9 AM
    timezone: "America/New_York",
  }
)
```

Cron expressions follow the standard 5-field format. Timezone support uses the IANA timezone database with UTC as the storage format.

## Interval-based Repetition

Repeat a job at fixed intervals:

```typescript
await queue.add(
  "health-check",
  { endpoint: "/api/health" },
  {
    repeat: {
      every: 30000, // Every 30 seconds
      limit: 10, // Maximum 10 executions
    },
  }
)
```

## Scheduling Options

| Option     | Type     | Description                              |
| ---------- | -------- | ---------------------------------------- |
| `delay`    | `number` | Milliseconds before job becomes eligible |
| `cron`     | `string` | Cron expression for recurring execution  |
| `timezone` | `string` | IANA timezone for cron scheduling        |
| `repeat`   | `object` | Interval-based repetition config         |

All timestamps are stored as UTC internally, regardless of the timezone specified in scheduling options.
